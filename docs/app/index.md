# Using Careportal in the App

## Open Webapp

After logging in through the web browser, the webapp is automatically loaded.
To return to the CgmSim configuration from the webapp, open the settings menu and select CgmSim.

## Installing mobile App

You can install and use the mobile app by visiting the Play Store or iOS Store.

Click on the images below to open the app:

[![Android App](../img/google_play.png)](https://play.google.com/store/apps/details?id=YOUR_APP_ID)

[![iOS App](../img/app_store.png)](https://apps.apple.com/app/idYOUR_IOS_APP_ID)

## Open Careportal

Open Careportal by pressing the **"+"** button in the middle of the page.
